## Workspace Configuration

Specify a workspace name and select a supported region. Consult [Azure services available by region](https://azure.microsoft.com/explore/global-infrastructure) for current availability.

**Pricing Tiers**
- **Premium:** Includes role-based access controls, Unity Catalog, SQL, Mosaic AI, serverless compute, Genie Code, and broader enterprise capabilities.
- **Trial:** Provides a 14-day evaluation of a Premium-level workspace.

> [!IMPORTANT]
> The Standard tier was retired for new workspaces on April 1, 2026. All new deployments now default to the Premium tier.
