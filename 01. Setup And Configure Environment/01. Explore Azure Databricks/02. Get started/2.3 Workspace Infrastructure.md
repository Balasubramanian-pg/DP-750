## Workspace Infrastructure

Select the deployment model that aligns with your networking and management requirements.

| Type | Description | Best For |
| :--- | :--- | :--- |
| **Serverless** | Pre-configured with serverless compute and managed storage. | Most general use cases. |
| **Hybrid (Classic)** | Provisions compute and storage directly in your Azure subscription. | Custom networking or on-premises connectivity. |

**Managed Resource Group**
Optionally specify a name for the automatically created resource group where Azure manages the underlying infrastructure resources.

> [!TIP]
> A **Free Edition** is available for students and educators. It has no time limit or payment requirement but includes daily usage limits and excludes classic compute. See [Sign up for Azure Databricks](https://learn.microsoft.com/en-us/azure/databricks/getting-started/free-trial-vs-free-edition) for details.

> [!NOTE]
> To deploy via the command line, use the **[az databricks workspace](https://learn.microsoft.com/en-us/cli/azure/ext/databricks/databricks/workspace)** command.

```
az databricks workspace create --resource-group myresourcegroup \ --name mydatabricksws \ --location westus2 \ --sku premium
```


```
az databricks workspace create --resource-group myresourcegroup \ --name mydatabricksws \ --location westus2 \ --sku premium
```

The equivalent [New-AzDatabricksWorkspace](https://learn.microsoft.com/en-us/powershell/module/az.databricks/new-azdatabricksworkspace) PowerShell cmdlet:

```
New-AzDatabricksWorkspace -Name mydatabricksws -ResourceGroupName myresourcegroup -Location westus2 -ManagedResourceGroupName databricks-group -Sku premium
```


```
New-AzDatabricksWorkspace -Name mydatabricksws -ResourceGroupName myresourcegroup -Location westus2 -ManagedResourceGroupName databricks-group -Sku premium
```
