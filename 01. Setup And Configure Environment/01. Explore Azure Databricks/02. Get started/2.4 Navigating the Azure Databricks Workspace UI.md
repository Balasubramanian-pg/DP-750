## Navigating the Azure Databricks Workspace UI

The workspace UI serves as the central hub for managing data, compute, and collaborative assets. Upon provisioning, the interface presents a streamlined homepage with shortcuts to essential tasks like importing data, creating notebooks, or configuring AutoML experiments.

### Interface Layout

**Sidebar Navigation**
The sidebar organizes resources into high-level categories—Workspace, Recents, Catalog, Jobs & Pipelines, Compute, and Marketplace—before breaking them down by product area:

| Product Area | Key Components |
| :--- | :--- |
| **SQL** | SQL Editor, Queries, Dashboards, Genie, Alerts, Query History, SQL Warehouses |
| **Data Engineering** | Job Runs, Data Ingestion |
| **Machine Learning** | Playground, Experiments, Features, Models, Serving |

**Top Bar Utilities**
Use the global search bar to locate any workspace object instantly, including notebooks, queries, dashboards, Unity Catalog tables, jobs, and repos. It also provides quick access to your recently viewed items.

### Creating Resources

Select **+ New** to initialize either workspace objects or compute infrastructure:

*   **Workspace Objects:** Notebooks, queries, repos, dashboards, alerts, jobs, pipelines, experiments, models, and serving endpoints.
*   **Compute Resources:** Clusters, SQL warehouses, and ML endpoints.

> [!TIP]
> The interface supports multiple languages. To adjust your preference, select your username in the top navigation bar, navigate to **Settings**, and update the language on the **Preferences** tab.
