# Get started with Azure Databricks

To use Azure Databricks, you must create an Azure Databricks workspace in your Azure subscription. A workspace is an Azure Databricks deployment in a cloud service account. It provides a unified environment for working with Azure Databricks assets for a specified set of users.
You can create an Azure Databricks workspace by:
- Using the Azure portal user interface.
- Using an Azure Resource Manager (ARM), Bicep or Terraform template.
- Using the New-AzDatabricksWorkspace Azure PowerShell cmdlet.
- Using the az databricks workspace create Azure command line interface (CLI) command.
When you create a workspace, you must specify:
- A workspace name.

- Select an available region. For available regions, see [Azure services available by region](https://azure.microsoft.com/explore/global-infrastructure).

## A pricing tier:

**Workspace Tiers**

| Tier | Details |
| :--- | :--- |
| **Premium** | Role-based access controls, Unity Catalog, SQL, Mosaic AI, serverless compute, Genie Code, and enterprise features. |
| **Trial** | 14-day free trial of a Premium workspace. |
| **Standard** | Retired for new workspaces as of April 1, 2026. All new deployments default to Premium. |

**Infrastructure and Settings**

| Component | Configuration |
| :--- | :--- |
| **Serverless** | Pre-configured with serverless compute and managed storage. Recommended for general use. |
| **Hybrid (Classic)** | Provisions compute and storage within your Azure subscription. Required for custom networking or on-premises connectivity. |
| **Managed Resource Group** | An optional, automatically generated resource group where Azure manages the underlying infrastructure. |

## Workspace Configuration

Specify a workspace name and select a supported region. Consult [Azure services available by region](https://azure.microsoft.com/explore/global-infrastructure) for current availability.

**Pricing Tiers**
- **Premium:** Includes role-based access controls, Unity Catalog, SQL, Mosaic AI, serverless compute, Genie Code, and broader enterprise capabilities.
- **Trial:** Provides a 14-day evaluation of a Premium-level workspace.

> [!IMPORTANT]
> The Standard tier was retired for new workspaces on April 1, 2026. All new deployments now default to the Premium tier.

## Workspace Infrastructure

Select the deployment model that aligns with your networking and management requirements.

| Type | Description | Best For |
| :--- | :--- | :--- |
| **Serverless** | Pre-configured with serverless compute and managed storage. | Most general use cases. |
| **Hybrid (Classic)** | Provisions compute and storage directly in your Azure subscription. | Custom networking or on-premises connectivity. |

**Managed Resource Group**
Optionally specify a name for the automatically created resource group where Azure manages the underlying infrastructure resources.

> [!TIP]
> A **Free Edition** is available for students and educators. It has no time limit or payment requirement but includes daily usage limits and excludes classic compute. See [Sign up for Azure Databricks](https://learn.microsoft.com/en-us/azure/databricks/getting-started/free-trial-vs-free-edition) for details.

> [!NOTE]
> To deploy via the command line, use the **[az databricks workspace](https://learn.microsoft.com/en-us/cli/azure/ext/databricks/databricks/workspace)** command.

```
az databricks workspace create --resource-group myresourcegroup \ --name mydatabricksws \ --location westus2 \ --sku premium
```


```
az databricks workspace create --resource-group myresourcegroup \ --name mydatabricksws \ --location westus2 \ --sku premium
```

The equivalent [New-AzDatabricksWorkspace](https://learn.microsoft.com/en-us/powershell/module/az.databricks/new-azdatabricksworkspace) PowerShell cmdlet:

```
New-AzDatabricksWorkspace -Name mydatabricksws -ResourceGroupName myresourcegroup -Location westus2 -ManagedResourceGroupName databricks-group -Sku premium
```


```
New-AzDatabricksWorkspace -Name mydatabricksws -ResourceGroupName myresourcegroup -Location westus2 -ManagedResourceGroupName databricks-group -Sku premium
```

## Navigating the Azure Databricks Workspace UI

The workspace UI serves as the central hub for managing data, compute, and collaborative assets. Upon provisioning, the interface presents a streamlined homepage with shortcuts to essential tasks like importing data, creating notebooks, or configuring AutoML experiments.

### Interface Layout

**Sidebar Navigation**
The sidebar organizes resources into high-level categories—Workspace, Recents, Catalog, Jobs & Pipelines, Compute, and Marketplace—before breaking them down by product area:

| Product Area | Key Components |
| :--- | :--- |
| **SQL** | SQL Editor, Queries, Dashboards, Genie, Alerts, Query History, SQL Warehouses |
| **Data Engineering** | Job Runs, Data Ingestion |
| **Machine Learning** | Playground, Experiments, Features, Models, Serving |

**Top Bar Utilities**
Use the global search bar to locate any workspace object instantly, including notebooks, queries, dashboards, Unity Catalog tables, jobs, and repos. It also provides quick access to your recently viewed items.

### Creating Resources

Select **+ New** to initialize either workspace objects or compute infrastructure:

*   **Workspace Objects:** Notebooks, queries, repos, dashboards, alerts, jobs, pipelines, experiments, models, and serving endpoints.
*   **Compute Resources:** Clusters, SQL warehouses, and ML endpoints.

> [!TIP]
> The interface supports multiple languages. To adjust your preference, select your username in the top navigation bar, navigate to **Settings**, and update the language on the **Preferences** tab.

## Get help from Genie Code
Genie Code (formerly Databricks Assistant) is an AI-powered pair programmer and support tool that helps you work more efficiently in Databricks by generating, explaining, and fixing code or queries directly in notebooks, dashboards, and files.
It can assist with a wide range of tasks, including identifying and correcting errors, creating data visualizations, diagnosing job issues, and filtering or analyzing data using natural language prompts. Genie Code can surface relevant guidance from the Azure Databricks documentation.
Genie Code also includes Agent mode, which is generally available for data science, data engineering, and dashboard authoring. Agent mode extends Genie Code with agentic capabilities so it can autonomously plan and complete multi-step data tasks on your behalf.
By using Unity Catalog metadata, it personalizes its responses based on your organization’s data assets—tables, columns, and descriptions—making it easier to explore and work with your data.
