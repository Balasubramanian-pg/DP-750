## 3. Define Relationships: Joins and Prompt Matching

Genie needs to know how tables connect and what values they contain to write accurate SQL.

### Join Relationships
While Genie can detect foreign keys from Unity Catalog, you should explicitly define joins for clarity and complex logic.
*   **Example:** Link `opportunity` to `accounts` via `opportunity.accountid = accounts.id`.
*   **Cardinality:** Specify if the relationship is One-to-One, One-to-Many, etc. This helps Genie avoid duplicate rows in aggregations.

### Prompt Matching
Prompt matching helps Genie understand the actual data values within your columns.
*   **Format Assistance:** Shows Genie representative examples of data formats (e.g., date styles, currency symbols).
*   **Entity Matching:** Curates a list of distinct values for categorical columns (e.g., State Codes like 'CA', 'NY'). When a user asks for "California," Genie knows to look for 'CA'.
    *   **Limit:** Up to 1,024 distinct values per column across 120 columns.
    *   **Refresh:** Regularly refresh prompt matching data to capture new values as your data evolves.
