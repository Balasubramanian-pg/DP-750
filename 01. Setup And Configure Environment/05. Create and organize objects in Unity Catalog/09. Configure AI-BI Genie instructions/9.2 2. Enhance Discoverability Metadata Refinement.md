## 2. Enhance Discoverability: Metadata Refinement

Unity Catalog provides the structural metadata, but Genie spaces allow you to layer **business context** on top of it without altering the underlying objects. This is done in the **Configure > Data** section.

### Table and Column Descriptions
Replace technical jargon with plain language.
*   **Technical:** `fcst_cat` stores forecast category codes.
*   **Business-Ready:** "Indicates whether an opportunity is in the Pipeline, Best Case, or Commit stage."

### Synonyms
Users rarely speak in database column names. Add synonyms to help Genie map natural language to your schema.
*   **Column:** `fcst_cat`
*   **Synonyms:** "forecast," "pipeline status," "category," "stage."

### Hiding Technical Columns
Surrogate keys, internal IDs, and audit timestamps often confuse both users and AI. Hide these columns to keep the interface clean and focus Genie on business-relevant data.
