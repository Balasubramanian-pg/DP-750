## Microsoft Purview

Microsoft Purview is a comprehensive data governance service designed to manage and oversee data across on-premises systems, multiple clouds, and SaaS platforms. It provides essential capabilities for data discovery, classification, lineage tracking, and access governance.

### Integration with Azure Databricks
When integrated with Azure Databricks and Unity Catalog, Purview discovers Lakehouse data and ingests its metadata into the **Data Map**. This creates a central catalog that unifies metadata from diverse sources, allowing you to apply consistent governance policies across your entire data environment.

**Key Capabilities of the Integration**

*   **Flexible Scanning:** Scan Azure Databricks environments in both public and private networks, powered by the fully managed Microsoft Purview integration runtime.
*   **Targeted Metadata Ingestion:** Choose to scan the entire Unity Catalog metastore or limit the scope to selective catalogs based on your governance needs.
*   **Comprehensive Metadata Extraction:** Capture detailed information about metastores, catalogs, schemas, tables, views, and columns.
*   **Automated Classification:** Identify sensitive data using built-in system classification rules or custom rules defined by your organization.
*   **End-to-End Lineage:** Gain detailed visibility into how data is transformed and moved across different systems and processes, including deep insights into transformations within Azure Databricks.
*   **Scheduled or On-Demand Execution:** Run scans manually as needed or configure recurring schedules (daily, weekly, or monthly) to keep metadata current.

> [!NOTE]
> In addition to Unity Catalog, Microsoft Purview can also scan the **workspace-level Hive metastore** in Azure Databricks, ensuring that legacy or non-Unity Catalog assets are also included in your governance framework.
