## Integration scenarios
The integration between Azure Databricks and Power Platform transforms the Lakehouse from a backend analytics engine into an active participant in daily business workflows. By connecting governed data to low-code tools, organizations can build applications that are both agile for users and secure for engineers.

### Practical Use Cases

#### 1. Planning and Forecasting Applications
Business users often need to adjust forecasts, revenue targets, or budget allocations outside of traditional BI tools. A Power App connected to Unity Catalog enables this write-back capability securely.

-   **Workflow:** Users submit adjustments via a canvas app form.
-   **Governance:** OAuth authentication ensures row-level security; users only see and modify data they own.
-   **Auditability:** All changes are written directly to a Delta table, preserving full transaction history and audit logs within Unity Catalog.

#### 2. Automated Data Quality Workflows
Data quality monitoring can be automated using Power Automate flows that act as the orchestration layer between detection and remediation.

-   **Detection:** A scheduled flow executes a SQL query against Databricks to evaluate quality metrics.
-   **Response:** If thresholds are breached, the flow triggers notifications to the data team or initiates a Databricks repair job automatically.
-   **Escalation:** Severity-based logic determines whether to attempt auto-repair or escalate to human review, reducing alert fatigue.

#### 3. Event-Driven Data Processing
Real-time business events can trigger immediate data processing without custom integration code.

-   **Trigger:** A flow monitors a business system (e.g., CRM, ERP) for specific events like new orders or completed transactions.
-   **Execution:** The flow passes relevant parameters to a Databricks job and waits for completion.
-   **Feedback Loop:** Upon success, the flow updates the source business system with processing results, closing the loop between operational and analytical systems.

#### 4. Dashboard Refresh Automation
Ensure business intelligence assets remain current without manual intervention from the data engineering team.

-   **Preparation:** A scheduled flow executes SQL to aggregate and prepare reporting datasets.
-   **Refresh:** The flow triggers a semantic model refresh in Power BI or Fabric once the data preparation is complete.
-   **Outcome:** Business users access up-to-date insights on a predictable schedule, decoupled from ad-hoc engineering requests.

### Governance Preservation Across Platforms

A defining characteristic of these scenarios is that **governance travels with the data**. Unity Catalog continues to enforce all security policies, column masking, and access controls even when interactions originate from Power Platform.

> [!IMPORTANT]
> This integration model resolves the tension between accessibility and control. Business users gain the ability to interact with data through familiar, intuitive interfaces, while data engineers maintain centralized authority over data quality, security, and compliance. The result is a self-service environment that does not compromise the integrity of the enterprise data estate.
