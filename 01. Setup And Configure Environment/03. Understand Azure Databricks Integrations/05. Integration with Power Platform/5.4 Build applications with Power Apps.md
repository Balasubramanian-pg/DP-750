## Build applications with Power Apps

Power Apps enables the creation of custom canvas and model-driven applications that interact directly with data stored in Azure Databricks. This integration transforms the Lakehouse from a backend analytics engine into a dynamic source for business-facing interfaces, supporting data entry, approval workflows, and interactive dashboards.

### Canvas Apps: Direct Data Interaction

When building canvas apps, you connect directly to Unity Catalog to select specific catalogs and tables. This direct connection supports full CRUD (Create, Read, Update, Delete) operations, allowing users to modify lakehouse data through intuitive forms.

*   **Real-Time Governance:** When using **OAuth authentication**, Unity Catalog evaluates each user’s permissions in real time. This ensures that row-level security filters, column masks, and table access controls are strictly enforced within the app interface.
*   **Security Without Compromise:** Business users can interact with trusted, governed data without requiring direct access to the underlying storage or compute infrastructure.

### Model-Driven Apps: Virtual Tables

For scenarios requiring structured forms, complex views, and deep business logic, Power Apps supports **Dataverse virtual tables** backed by Azure Databricks data.

*   **No Data Duplication:** Virtual tables integrate Databricks data into the Microsoft Dataverse ecosystem without physically copying it, saving on storage costs.
*   **Unified Experience:** Allows you to build model-driven apps that treat Databricks data as if it were native Dataverse data, leveraging standard Power Platform features like relationships and business rules.

> [!TIP]
> **Performance Consideration**
> For optimal query response times, prefer **direct connections** over virtual tables whenever possible. While virtual tables offer architectural benefits by avoiding data duplication, direct connections typically provide faster performance for interactive app experiences.

### Handling Bulk Operations with Power Automate

While canvas apps are excellent for individual record interactions, they are not optimized for large-scale data modifications. For bulk updates, integrate **Power Automate flows**:

*   **Batch Processing:** Flows can process multiple changes in a single batch, significantly improving efficiency compared to individual API calls from a canvas app.
*   **Workflow Orchestration:** Use flows to trigger complex multi-step processes, such as validating data in Databricks before committing changes or triggering downstream jobs upon data submission.

> [!NOTE]
> By combining canvas apps for user interaction, virtual tables for structured logic, and Power Automate for bulk processing, you can create comprehensive business solutions that are both secure and performant, all built on the foundation of your governed Azure Databricks data.
