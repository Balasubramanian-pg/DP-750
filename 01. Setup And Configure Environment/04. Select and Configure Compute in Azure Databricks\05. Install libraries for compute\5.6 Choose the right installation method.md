## Choose the right installation method
Different library installation methods suit different scenarios. The following diagram illustrates a decision flow to help you select the appropriate installation approach:

```mermaid
graph TD
    A[Library Installation Requirement] -->|System-level config or OS packages| B[Init Scripts]
    A -->|Application Dependencies| C{Access Mode?}
    
    C -->|Standard Access Mode| D[Metastore Admin Approval]
    C -->|Dedicated/Single-User| E{Source Type?}
    
    D --> F{Library Source?}
    F -->|Public Repository PyPI/Maven| G[Add Coordinates to Allowlist]
    F -->|Internal/Custom Files| H[Add File Path to Allowlist]
    
    E -->|Public Repository| I[Install via Cluster Library UI]
    E -->|Internal/Custom Files| J[Store in Unity Catalog Volume]
    
    G --> K[Install via Cluster Library UI]
    H --> K
    J --> L[Install from Volume Path]
    I --> M[Library Ready]
    K --> M
    L --> M
    B --> N[System Config Applied]
```
