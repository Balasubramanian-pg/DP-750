# Select and Configure Compute in Azure Databricks

## Description
Choose appropriate compute types for different Azure Databricks workloads; Configure compute performance settings including node types, autoscaling, and termination; Enable compute features like Photon acceleration and select appropriate Databricks Runtime versions; Configure compute access permissions and dedicated group access modes; Install and manage libraries on compute resources using various methods
