# Understand Azure Databricks architecture

## Description
Describe the Azure Databricks account hierarchy and how it organizes resources; Explain the difference between control plane and compute plane; Understand the role of workspace storage in Azure Databricks; Describe default storage capabilities in serverless workspaces; Explain how external locations connect cloud storage to Unity Catalog; Understand how Unity Catalog managed storage organizes data across catalogs and schemas
