## Learning Objectives
Monitor and manage cluster consumption using metrics, auto-termination, and budgets; Troubleshoot and repair failed Lakeflow Jobs using the Jobs UI and repair run feature; Diagnose Spark job failures and resource bottlenecks using the Spark UI and compute metrics; Investigate and resolve caching, data skew, memory spill, and shuffle performance issues; Implement log streaming from Azure Databricks to Azure Log Analytics for centralized monitoring
