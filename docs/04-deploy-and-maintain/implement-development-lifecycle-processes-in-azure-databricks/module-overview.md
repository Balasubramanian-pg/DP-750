# Implement development lifecycle processes in Azure Databricks

## Details
- **Duration:** 87 min
- **Microsoft Learn URL:** [Implement development lifecycle processes in Azure Databricks](https://learn.microsoft.com/en-us/training/modules/implement-development-lifecycle-processes-in-azure-databricks/)

## Learning Objectives
Apply Git version control best practices using Git folders in Azure Databricks; Manage branching, pull requests, and conflict resolution for collaborative development; Implement a testing strategy including unit, integration, end-to-end, and user acceptance tests; Configure and customize Declarative Automation Bundles for deployment automation; Deploy bundles using the Databricks CLI across development and production environments
