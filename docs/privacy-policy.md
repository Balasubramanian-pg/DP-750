# Privacy Policy

**Last Updated:** October 2026

### 1. Architectural Privacy Principles
The DP-750 study hub is engineered as an immutable, static documentation portal hosted via GitHub Pages. Our core design tenet is total anonymity: **no accounts, no logins, no personal data ingestion pipelines**.

### 2. Information Handled
- **Exam Simulator State:** All interactions with the 181+ question bank occur entirely in-memory and in your local browser session. No telemetry or answer records are dispatched to external servers.
- **Hosting Telemetry:** Basic connection logs (such as requesting IP address and User-Agent) are processed transiently by GitHub infrastructure to serve static web assets under standard web protocols and DDoS protection policies.

### 3. External Links & Azure Services
Course documentation contains references to official Microsoft Learn and Databricks endpoints. When navigating to third-party domains, their respective privacy documentation applies.

### 4. Open Source Governance
All content and study tooling in this repository are maintained as open resources for technical engineers preparing for enterprise cloud certification.

For questions or repository contributions, visit the [GitHub Repository](https://github.com/Balasubramanian-pg/DP-750).
